# TabulaSense
掃除ロボット


カメラでテーブル上の汚れや残量を認識し、アームに取り付けたワイパー/モップでテーブル表面を自動で吹き上げる機能



開発目標（MVP）

3D仮想空間において、以下の動作シーケンスを完全自動で一連実行できるシステムを構築する。

アプローチ: ロボットがテーブル横に移動・停止する。

センシング: アーム先端（または本体）のRGB-Dカメラでテーブル表面を撮影する。

認識・分類:

「片付けるべき物体」（ペットボトル、コップ等）を検出・位置（3D座標）の特定。

「拭き取るべき汚れ」（液体こぼれ、粉じん等）の領域（ポリゴン）の特定。

物体除去（ピック＆プレイス）: アーム（ハンド）で物体を掴み、回収箱へ移動。

拭き上げ動作（ワイピング軌道生成）: ワイパーツールに切り替え（またはアーム拭き取りアタッチメントで）、汚れ領域全体をカバーする拭き取り軌道を追従。
