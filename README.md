# TabulaSense

> カメラでテーブルの上を認識し、**片付け**と**拭き上げ**を自動で行う掃除ロボット。台車が付いており、テーブル間を移動する。
>
> A cleaning robot that sees the table with a camera and automatically **clears** it and **wipes** it down.


## 概要 / Overview

TabulaSense は、施設内を移動し、テーブルの上にある「片付けるべき物」と「拭き取るべき汚れ」をカメラで見分け、
アームで物を回収したあと、ワイパー／モップでテーブル表面を自動で拭き上げるロボットです。
また下げ膳なども行います。スタッフのやり方を見て真似し、言われたことを覚えていく自己学習機能を備えています。

1〜2 理解する：スタッフが丸いテーブルを指さして「このテーブルを拭いて」と言います。LLMが言葉から「拭く」という作業を読み取り、Molmo2-ERが指さしの先からテーブルを推定します。テーブルが並んでいて自信がなければ、「この丸いテーブルですね？」と確認します

3 やり方を探す：記憶の動作辞書に「拭く」がないので、「一度やって見せてもらえますか？」と頼みます。スタッフが拭く様子を撮り、HOSTが動作を覚えます

4〜5 やってみる：Molmo2-ERが「テーブル全体に手が届く位置」を決め、Nav2がそこまで移動して止まります。その後、MolmoAct2が覚えた動きでゆっくり拭きます

6 確かめる：カメラで拭き残しを確認し、残っていればその部分をやり直します

7 教わる：スタッフの指摘は内容で行き先が分かれます

「もう少し強く押して」のような動きのずれ：CorrectVLAでその場で補正する
「端まで拭いて」のような意味の指摘：「拭く時は端まで／食べこぼしが残りやすいから」と、理由ごと記憶層に保存する

8 身につける：その日の記録で夜間に学習し、テストに合格したら翌日のモデルに反映されます
